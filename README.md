# Usage

The server can be launched by executing
```bash
python3 server.py
```
or
```bash
python3 watcher.py
```
First command will just launch the server. The second command will launch a watcher script whihc will relaunch the
server every time a source code file changes.

The server is launched at http://localhost:8080/
The three apps are deployed at:
- http://localhost:8080/graph
- http://localhost:8080/erthaos
- http://localhost:8080/grundform
